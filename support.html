Help with StatLife, Guided Mode, Professional Mode and StatLife Pro.

Getting Started / 开始使用

Guided Mode / 引导模式

Start by choosing what you want to learn from your data. StatLife will guide you through a series of questions, help determine an appropriate analysis path, and show the required data input.

从“你想知道什么”开始，根据页面引导回答问题并输入数据。 「算咯」会根据你的目的和数据，引导你进入适合的分析路径。

Professional Mode / 专业模式

If you already know which statistical method you need, Professional Mode lets you select a method directly, enter your data, and view detailed results.

如果你已经知道需要使用的统计方法，可以直接进入专业模式， 选择方法、输入数据并查看详细结果。

Data & CSV / 数据与 CSV

Manual Data Entry / 手动输入

Data can be entered directly in the input fields provided for each analysis.

你可以根据不同分析页面提供的输入区域直接填写数据。

CSV Import / CSV 导入

Supported analyses allow data to be imported from CSV files. The required CSV structure may vary depending on the selected statistical method.

支持 CSV 的分析页面可以直接导入 CSV 文件。 不同统计方法需要的数据结构可能有所不同，请按照对应输入页面的格式准备数据。

StatLife Pro

Pro Features / Pro 功能

Some advanced statistical methods require StatLife Pro. Available Pro options and pricing are displayed inside the app before purchase.

部分高级统计方法需要 StatLife Pro。 购买前可以在 App 内查看当前提供的 Pro 方案及价格。

Restore Purchases / 恢复购买

If you previously purchased an eligible StatLife Pro product using the same Apple Account, use the Restore Purchases option inside StatLife.

如果你曾使用同一 Apple 账户购买符合条件的 StatLife Pro， 可以在 App 内使用“恢复购买”功能恢复购买状态。

Subscriptions / 订阅

Subscription billing and management are handled through your Apple Account and the App Store.

StatLife Pro 订阅的付款与订阅管理通过 Apple 账户及 App Store 完成。

About the Results / 关于分析结果

The Taoist, Witch, oracle and divination elements in StatLife are presentation themes. Statistical results are calculated from the data provided by the user. StatLife does not provide supernatural predictions.

「算咯」中的道士、女巫、卦象及占卜元素均属于界面和表达主题。 分析结果依据用户提供的数据进行计算，「算咯」不提供超自然预测。
